# Walkthroughs

Open notebooks from this directory or from the project root after installing `pip install -e .`. Optional Jupyter installation: `pip install '.[notebooks]'`.

| Notebook | Default execution |
|---|---|
| `01_kosmos_baseline.ipynb` | Preview image-only prompt; inference opt-in |
| `02_metadata_prompting.ipynb` | Show conservative filename hints and prompt variants |
| `03_embedding_retrieval.ipynb` | Search preserved captions using offline TF-IDF; neural retrieval opt-in |
| `04_rag_evaluation.ipynb` | Preview paired prompts and metric examples; no API calls |

`archive/` contains historical source only. It has been sanitized and its outputs cleared, but may contain missing variables, incompatible APIs and notebook-state dependencies. Use maintained modules for new experiments.
